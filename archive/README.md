# EduRisk Archive & Historical Backups

This directory preserves historical versions, prototypes, and refactoring snapshots from earlier project phases for reproducibility, audit trails, and archival preservation.

---

## 📂 Subdirectories

- **`pre_simplification_backup/`**: Snapshot prior to code consolidation and architectural refactoring.
- **`v1_legacy_root_modules/`**: Legacy Phase 1 monolithic prototypes and utility scripts.
- **`v2_phase2_prototype/`**: Early Phase 2 candidate model prototypes and evaluation logs.

> **Note**: Active, production-ready code is located in the root directories (`app.py`, `src/`, `app_pages/`, `services/`, `database/`, `config/`, `models/`, and `tests/`).
